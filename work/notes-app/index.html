About the project

Built during ACM Summer Explore at BITS Pilani, Notes App put authentication and asynchronous data into a small mobile application. Google sign-in opens the account flow, and a Cloud Firestore collection supplies the note grid through a live snapshot stream. Separate screens handle creating and editing notes, while deletion updates the collection and the displayed list. The project helped me connect mobile navigation, editable forms, and remote data updates in one application. The interface reflects database changes without requiring a manual refresh.

What I built

  • Connected Firebase Authentication and Google sign-in to the application navigation.
  • Used a Firestore snapshot stream to update the note grid as documents changed.
  • Built note creation, editing, and deletion screens around Firestore document operations.
