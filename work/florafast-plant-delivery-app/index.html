About the project

FloraFast follows the main steps of a mobile shopping experience: create an account, browse a plant catalog, open a product, save favorites, and add items to a cart. Firebase Authentication handles email sign-up, sign-in, and password resets. Product screens share a static plant model with local favorite and cart state. I used the project to develop reusable Flutter screens and connect account flows to a broader application. The scan screen is a visual prototype; plant recognition, checkout, and persisted shopping data were not implemented.

What I built

  • Connected Firebase Authentication to sign-up, sign-in, and password-reset screens.
  • Built catalog, product-detail, favorites, profile, and cart views using shared plant data and local selection state.
  • Created a scan interaction mockup to explore the interface. The implemented app uses a sample catalog and in-memory shopping state.
