iworkslab - Food Delivery App

A Flutter food-store prototype with shared product, cart, and order state built using Provider and ChangeNotifier.

Flutter, App Development

About the project

This app connects product browsing to a cart and order history through a shared state model. Users can save products, change quantities, inspect totals, and submit the current cart to the order view. Provider and ChangeNotifier keep these interactions consistent across screens, while reusable widgets support the login, catalog, and product layouts. The project focuses on application state and responsive presentation. Its catalog, authentication screens, and orders use local demo data; backend persistence, payment processing, and fulfillment are outside the implementation.

What I built

  • Separated product, cart, and order data into observable models so updates could reach multiple Flutter screens.
  • Implemented favorite selection, item quantities, cart totals, and a local order-history flow.
  • Built reusable responsive interface components around a sample catalog and in-memory data.
