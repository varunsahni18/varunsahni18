About the project

MyAI routes requests through deterministic logic, cached answers, local tools, and model inference. I tested a quantized Qwen bundle through Qualcomm Genie on Snapdragon 8 Elite. The default APK has no Android INTERNET permission, and a build guard prevents it from being added accidentally.

What I built

  • Built an Android assistant with a four-tier routing design: deterministic keyword matching, response caching, local tools, and Genie-backed model inference. In the public implementation, the two model tiers share a runtime callback.
  • Tested a quantized Qwen2.5-VL-7B bundle on Snapdragon 8 Elite through Qualcomm Genie. The public source requires external Genie runtime artifacts for the NPU path.
  • Shipped the default APK without INTERNET permission and added a Gradle build guard against accidentally introducing it.
  • Implemented local calculator, datetime, calendar, contacts, and alarm tools with structured JSON calls.
