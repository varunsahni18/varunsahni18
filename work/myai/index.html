About the project

MyAI explores how much a personal assistant can do directly on a phone. Simple requests use deterministic matching, previously accepted answers, or tools for calculations, dates, calendar events, contacts, and alarms. Requests that need generation reach a local model through Qualcomm Genie. I tested a quantized Qwen bundle on Snapdragon 8 Elite and connected structured model output to the tool layer. The default Android app omits INTERNET permission, and a Gradle check prevents the permission from being added accidentally.

What I built

  • Implemented routing between keyword matches, cached responses, device tools, and a shared Genie model callback, avoiding model work for requests handled by earlier paths.
  • Used structured JSON tool calls to connect generated requests to calculator, date and time, calendar, contacts, and alarm operations.
  • Added a feedback-based response cache and a build-time network-permission guard. The public source needs external Genie runtime artifacts to reproduce the NPU path.
