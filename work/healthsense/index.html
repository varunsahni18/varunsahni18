About the project

HealthSense explores how ECG, EEG, PPG, EMG, and motion signals can share one analysis interface. The implemented pipeline combines signal-processing heuristics with a small PyTorch convolutional model for ECG classification, exported for ONNX Runtime inference. Agent components organize the results and provide explanations in the dashboard. I also used simulated adaptation curves to demonstrate how a future personalization workflow could appear. The completed work is a systems prototype and a small ECG experiment, with clinical validation and on-device training still to be done.

What I built

  • Connected five signal types to preprocessing, task-specific outputs, and a common dashboard for inspecting the analysis.
  • Built a compact 1D ECG CNN in PyTorch with training and ONNX export scripts, plus runtime provider selection with a CPU fallback.
  • Tested ECG classification on a small, four-record PhysioNet sample. The experiment used window-level splits; it does not establish performance on unseen patients. BioTrain adaptation is simulated.
