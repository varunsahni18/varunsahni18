Database Management System, Flutter

About the project

Live Train Status connects a database-systems project to a mobile interface. The SQL schema models trains, stations, schedules, routes, and delays, while queries and views derive possible journeys and arrival estimates. Flutter screens fetch JSON data for train lookup and status views, with a separate administrative flow for delay updates. The project let me work through the full path from relational data modeling to asynchronous mobile presentation. The repository preserves the schema and app; the original external backend is not maintained as a live railway service.

What I built

  • Modeled stations and ordered train stops in SQL and used relational queries to find journeys between a source and destination.
  • Connected Flutter train, station, and schedule models to JSON endpoints for lookup and status screens.
  • Built an administrative delay-update interface and queries for estimated arrival information as part of the coursework prototype.
