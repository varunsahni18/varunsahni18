About the project

This project turns geographic coordinates into a navigable Unity scene. A location provider initializes the map, while mouse-look, movement, rotation, and zoom controls let a user explore the area. To move between distant coordinates, a C# coroutine first zooms out, interpolates the map center, and restores the destination zoom. That sequence keeps the transition understandable as the map changes. The original title and recording use MapMyIndia terminology; the public implementation uses Mapbox Unity components and represents a geographic viewer rather than a live synchronized digital twin.

What I built

  • Initialized the map from the first location update and connected latitude and longitude input to the map center.
  • Implemented a coroutine for zooming out, moving between coordinates, and zooming back in at the destination.
  • Added scene navigation controls around the SDK terrain and building layers, including movement, mouse-look, rotation, and scroll-wheel zoom.
