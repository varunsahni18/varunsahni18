About the project

Our team built a compiler front end to understand how source text becomes a structured program representation. A hand-written lexer produces tokens, and a table-driven LL(1) parser reads grammar productions and computes FIRST and FOLLOW sets. A separate pass reduces the parse tree to an abstract syntax tree. Symbol tables then track declarations, types, scopes, and offsets for semantic checks. The implementation includes panic-mode error recovery so parsing can continue after malformed input. Executable code generation was outside the completed implementation.

What I built

  • Implemented a DFA-based lexer and a stack-driven predictive parser with generated parsing tables and panic-mode recovery.
  • Constructed the AST and scoped symbol tables for functions, variables, arrays, type information, and storage offsets.
  • Added partial semantic checks and a driver for inspecting each front-end stage. The project was built by a five-person course team.
