About the project

Our team built the front end from source characters to structured program information. A DFA lexer feeds a table-driven LL(1) parser using FIRST and FOLLOW sets. The parse tree is reduced to an AST and connected to scope and type information through symbol tables. The implementation includes panic-mode error recovery and partial semantic analysis; executable code generation was not completed.

What I built

  • Built a compiler front end as a team project in C, with a DFA twin-buffer lexer and a table-driven LL(1) parser using FIRST/FOLLOW sets.
  • Constructed an AST and symbol tables, with scope/type checks, partial semantic analysis, and panic-mode error recovery. Executable code generation was not completed.
  • Compared parse-tree and AST node storage: one sample showed roughly 70% lower estimated node-structure memory, calculated from node counts and structure sizes.
