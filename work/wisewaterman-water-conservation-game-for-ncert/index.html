About the project

WiseWaterman makes water conservation part of the game rules. Players navigate obstacles using a jetpack with a limited water supply and collect question boxes along the route. Correct answers replenish the meter, while feedback explains the conservation lesson. The game was developed for an NCERT-funded effort overseen by Prof. Neetu Yadav. My contributions covered game design, animation, audio production, and writing. The published WebGL build and walkthrough show the playable experience; the public repository contains compiled game assets rather than the Unity source project.

What I built

  • Connected conservation questions to the resource mechanic so answering correctly affects how long the player can continue.
  • Contributed animation, audio, writing, and game-design work to the learning experience.
  • Published a Unity WebGL build that can be played in a browser without installing the game.
