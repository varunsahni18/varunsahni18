About the project

Code Buddy reviews code changes inside the engineering workflow, where a useful finding needs enough context to explain the problem and propose a fix. I architected the platform at Qualcomm around separate detection, repair, and validation steps coordinated through tool calls. Structural retrieval supplies relevant symbols and dependencies, and candidate changes pass validation guardrails before a review is posted. The platform grew from a pilot to more than two million automated reviews. My work also included an evaluation harness for comparing review quality as prompts and models changed.

What I built

  • Connected change events to a review pipeline that retrieves code context, detects issues, generates candidate fixes, and validates the result before delivery.
  • Built dependency-aware retrieval using Tree-sitter, symbol indexes, and cached lookups so reviewers could inspect definitions and call relationships beyond the changed lines.
  • Compared agent findings against labeled code changes using precision and recall, giving prompt and model updates a repeatable evaluation process.
